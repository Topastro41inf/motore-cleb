# REGOLA — Pagina Filo di Arianna dentro C.L.E.B.

## 1. Principio madre

C.L.E.B. coordina.  
Il Filo di Arianna resta separato.

Nel portale C.L.E.B. entra solo una porta leggera:
- spiegazione;
- orientamento;
- simulazione non sensibile;
- regole di accesso;
- collegamento concettuale al sistema madre.

Non entra il programma FdA reale.

---

## 2. Cosa NON deve entrare nel portale

Non inserire nel sito C.L.E.B.:

- motore completo FdA;
- audio reali;
- frequenze reali;
- rituali profondi;
- dati personali reali;
- letture reali;
- memoria rituale reale;
- codice profondo operativo;
- file o asset sensibili;
- promesse mediche o terapeutiche.

---

## 3. Regola di accesso

Il Filo di Arianna è accessibile solo a utenti C.L.E.B. attivi.

Non genera pallini aggiuntivi.

---

## 4. Dashboard e Custode

La Dashboard cliente può mostrare in futuro uno stato semplice:

```text
Filo di Arianna: disponibile / richiesto / non attivo
```

L’Area Custode può mostrare solo dati simulati o stati gestionali non sensibili.

---

## 5. Formula operativa

```text
C.L.E.B. apre il perimetro.
FdA orienta e armonizza.
Il sito spiega.
L’esperienza reale resta separata.
```
